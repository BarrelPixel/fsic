## OUR TARGET

FSIC aims for the website to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA.

---

## HOW THE SITE IS BUILT

- **Keyboard:** everything that can be clicked can be reached and used with a keyboard, and the keyboard focus is always visible (an orange outline).
- **Skip link:** a "Skip to main content" link at the top of every page.
- **Structure:** each page has one main heading and headings in order, so screen readers can move by section.
- **Images:** every meaningful image has a text description; decorative ones are hidden from screen readers.
- **Contrast:** text colors are checked against WCAG AA contrast.
- **Text size and zoom:** reading text is 18 pixels on a 28-pixel line, and pages work from 320 pixels wide, so they can be zoomed.
- **Motion:** if your device asks for reduced motion, the site turns animation off.
- **Without JavaScript:** every page can be read, and the desktop menus open on hover and keyboard focus. The phone menu needs JavaScript, but every page is also linked from the footer.
