## SEO/AEO Optimization Review Checklist

Before setting `status: review`, verify:

### Content structure:
- [ ] One clear question answered
- [ ] Answer-first summary is complete and standalone
- [ ] Every H2 is phrased as a question
- [ ] One-sentence definitions for key terms
- [ ] Paragraphs are 2-4 sentences (quotable chunks)
- [ ] Lists used for steps, requirements, or options

### Facts and sourcing:
- [ ] Every claim traces to a listed source
- [ ] Master Plan figures use `FIGURES` constants exactly
- [ ] Economic figures shown as ranges ($X–$Y billion)
- [ ] Time-sensitive facts are dated ("as of November 2026")
- [ ] No invented partners, statistics, or quotes

### SEO:
- [ ] Title ≤ 90 chars (aim for ≤ 60)
- [ ] Description 70-155 chars
- [ ] Question phrased as people search
- [ ] H2s match "People also ask" style questions
- [ ] Internal links to pillar page
- [ ] Internal links to related posts/pages
- [ ] Audiences tagged correctly

### AEO:
- [ ] Summary can be quoted alone
- [ ] Each section can be quoted alone
- [ ] FAQs section included (enables FAQPage schema)
- [ ] Answers are factual, not promotional
- [ ] Definitions are explicit, not implied

### Schema and technical:
- [ ] Topic is one of the 7 valid topics
- [ ] Follow-up specified (required before review)
- [ ] Follow-up slug matches naming convention
- [ ] Author exists in authors.ts
- [ ] All links use url('/path') or are built URLs
- [ ] `npm run check` passes (types)
- [ ] `npm run check-links` passes (no broken links)

## Measuring Success (after analytics setup)

Track for each post (Search Console + analytics):

1. **Impressions:** How often post appears in search results
2. **CTR:** Click-through rate from search results
3. **Queries:** What search terms bring visitors (real questions to answer)
4. **Answer engine citations:** Monthly check of ChatGPT, Perplexity, Gemini for post's question
5. **Engagement:** Time on page, scroll depth, clicks to pillar page
6. **Conversions:** Contact form submissions mentioning the topic

**Target (6 months after launch):**
- Every published post indexed
- Each ranking page 1 for its own question (Southeast Volusia searches)
- FSIC cited in ≥33% of answer engine responses for posts' questions
